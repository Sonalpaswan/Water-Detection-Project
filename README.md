# 💧 Water Quality Prediction using Machine Learning

This project predicts whether water is **safe or unsafe for drinking** using Machine Learning techniques.  
It uses various physicochemical parameters such as pH, Hardness, Solids, Chloramines, Sulfate, Conductivity, and Turbidity to determine water quality.

---

## 🚀 Features
- ✔ Predicts water potability (Safe / Not Safe)
- ✔ Clean and responsive web interface
- ✔ Built using Flask for backend
- ✔ Real-time prediction system
- ✔ Contact form with email functionality
- ✔ Simple and user-friendly UI

---

## 🧠 Machine Learning Workflow
- Data Cleaning & Preprocessing  
- Handling Missing Values  
- Feature Selection  
- Model Training  
- Model Evaluation using Accuracy & Confusion Matrix  
- Model Export using `.pkl` file  

---

## 🖥️ Tech Stack
- **Python**
- **Flask**
- **Machine Learning (Scikit-learn)**
- **Pandas, NumPy**
- **HTML, CSS**

---

## 📊 Model Details
- Algorithm Used: Random Forest Classifier  
- Accuracy: ~58%  
- Dataset: Water Potability Dataset
